# معرض أعمال بدر السلمي

موقع عربي متجاوب لعرض البرمجيات والمشاريع، مبني بـ React وTypeScript وVite. التصميم مستقل عن `LuminaUI`؛ وتظهر المكتبة كأحد المشاريع المعروضة فقط.

لملف مستقل يجمع نصوص الموقع ومشاريعه وصوره وتصميمه وطريقة عمله بالعربية والإنجليزية، راجع [`SITE_CONTENT.md`](SITE_CONTENT.md).

تُعرض المشاريع السبعة كبطاقات شبيهة بمتاجر التطبيقات، مجمّعة حسب المجال، مع بحث وتصفية. يدعم الموقع العربية والإنجليزية (مع تبديل اتجاه الصفحة)، والوضعين الفاتح والداكن؛ ويحتفظ بالاختيارين محليًا. شعار بدر الشخصي في `public/badr-mark.svg` ويظهر في الترويسة والتذييل وأيقونة التبويب. تستخدم الواجهة `@hugeicons/react` مع `@hugeicons/core-free-icons`، وتظهر شعارات التقنيات المعروفة من `simple-icons` بجانب أسمائها.

تفتح كل بطاقة صفحة تفاصيل على `/projects/:id` تتضمن المشكلة والحل وطريقة التنفيذ والميزات وصورة المشروع. يعمل التنقل الداخلي بزر الرجوع/التقدم في المتصفح، ويمكن فتح رابط التفاصيل أو إعادة تحميله مباشرة. نصوص الدراسات بالعربية والإنجليزية في `src/data/caseStudies.ts`، وتنسيقها في `src/styles.css`.

## صور المشاريع

- `public/hesah.webp` و`public/daris.webp`: صور للصفحتين التعريفيتين المنشورتين.
- `public/project-shots/arx/` و`hesah/` و`daris/`: لقطات إضافية قدّمها صاحب المشاريع من مجلدات سطح المكتب `arx sc` و`hesah sc` و`daris sc`؛ حُوّلت إلى WebP لتخفيف حجم التحميل مع إبقاء الصور الأصلية في مواضعها واللقطات السابقة في المعرض.
- `public/project-shots/trex-docs.png` و`mapx-docs.png`: لقطات من واجهتي التوثيق المنشورتين. الواجهة الموجودة خلف رابط Mapx تعرض اسم **Magret** حاليًا، وقد وُضّح ذلك في وصف الصورة.
- `public/project-shots/arx-desktop.png`: شاشة الإعداد الأولى من نسخة محلية نظيفة لـARX، بلا بيانات مستخدم.
- `public/lumina-banner.svg`: بانر من توثيق LuminaUI؛ و`public/project-shots/api-badr-architecture.png`: صورة معمارية من ملفات API-BADR. هاتان **صورتان توثيقيتان وليستا لقطتي تشغيل**.

تُحدَّد الصورة ونوعها ووصفها في `src/data/caseStudies.ts`. لا يُضاف رابط عام لمشروع بلا وجهة مؤكدة.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

## النشر على Vercel

اربط مستودع GitHub بمشروع جديد في Vercel. الإطار **Vite**، وأمر البناء `npm run build`، ومجلد الناتج `dist` (محدّدة أيضًا في `vercel.json`). يوجّه `vercel.json` روابط `/projects/:id` إلى التطبيق حتى يعمل فتح صفحة التفاصيل وتحديثها مباشرة. لا يحتاج الموقع إلى متغيرات بيئة.

روابط التواصل في التذييل تستخدم `tel:` و`mailto:` للهاتف والبريد الإلكتروني.

## إضافة مشاريع

تُدار المشاريع وترتيبها وتقنياتها من `src/data/projects.ts`. أضف عنصرًا جديدًا بمعلوماته الحقيقية وحدّد نوعه (`product` أو `api` أو `library`) ليظهر في مجموعته. أضف نصه الإنجليزي إلى `projectEnglish` في `src/i18n.ts`، ودراسة حالته وصوره إلى `src/data/caseStudies.ts`، وضع شعاره في `public/` وأضف مساره إلى `projectIcons` في `src/App.tsx`. شعار حِصّة مأخوذ من أيقونة التطبيق المنشورة في موقعه، وشعارات ARX وTrex وMapx من أصول مشروع ARX المحلية. شعارات دارس وAPI-BADR وLuminaUI رسومات SVG مخصّصة لهذا المعرض وليست شعارات رسمية. أضف شعار أي تقنية جديدة إلى `brandIcons` إن توفر.

لم يُضف رابط خارجي لـ `API-BADR` لأن رابط المستودع المذكور في ملفه التعريفي غير متاح حاليًا.

أُضيف ARX اعتمادًا على ملفات المشروع المحلية، دون رابط خارجي لعدم وجود رابط عام مؤكّد في ملفاته.
